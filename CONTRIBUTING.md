# Contributing to Veriqorn

Thank you for your interest in contributing. Contribution workflow and
supported development environments will be documented before the first
Community Core source release.

By submitting a contribution, you confirm that you have the right to submit it
under the Apache License 2.0.

## Developer Certificate of Origin

Veriqorn uses the Developer Certificate of Origin (DCO). Every commit proposed
for inclusion must include a `Signed-off-by` trailer, for example:

```text
Signed-off-by: Your Name <your.email@example.com>
```

Use `git commit -s` to add it automatically. By signing off, you certify that
you have the right to submit the contribution under the project's license.
