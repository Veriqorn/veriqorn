# Veriqorn Community v0.2.39

- Allow an operator to explicitly trust exact private HTTP(S) origins for extension network requests with `OUTBOUND_PRIVATE_ALLOWED_ORIGINS`. The destination must also match `OUTBOUND_ALLOWED_HOSTS`. Scheme, host and port must match; other private destinations remain denied.
- Pass both outbound policy variables through the canonical Compose deployment. Correct IPv6 literal lookup by resolving the normalized host without brackets.
- Test private-address denial by default, both allowlists, scheme/host/port boundaries, invalid origin configuration, embedded credentials and extension runtime propagation.

## Local LM Studio in Docker

Add `host.docker.internal` to `OUTBOUND_ALLOWED_HOSTS` and set `OUTBOUND_PRIVATE_ALLOWED_ORIGINS=http://host.docker.internal:1234` in `deploy/.env`. Use the LM Studio model identifier currently loaded in your local server. Recreate the backend after changing deployment environment values. Only configure exact origins you operate and trust.
