# Veriqorn Community v0.2.36

- Publish synchronized Community images and public SDK packages for the Enterprise v0.2.36 release.
- Enterprise v0.2.36 adds native repository evidence search and fresh source context for failure-analysis follow-up chat.
- Community remains self-hosted and includes the administrator-managed S3/MinIO storage introduced in v0.2.35.

## Upgrade

Upgrade backend and frontend together. Installations upgrading from v0.2.34 or earlier must also follow the [v0.2.35 storage migration instructions](v0.2.35.md).
