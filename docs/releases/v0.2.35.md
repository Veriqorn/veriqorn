# Veriqorn Community v0.2.35

- Add administrator-managed Amazon S3 and MinIO connections in Settings > Storage.
- Check object write/read/delete permissions before activation and switch new uploads without restarting the backend.
- Encrypt saved access keys, secret keys, and session tokens with an installation-level encryption key.
- Keep previous attachments accessible through their recorded storage connection, including legacy MinIO attachments.

- Include the signed Enterprise update and bind-mount environment-write fixes since v0.2.34.

## Upgrade

Existing installations keep using the original MinIO configuration until an
administrator activates another connection. Keep that MinIO service and its
credentials available while older files reference it. Automatic object migration
and automatic IAM role credential refresh are separate follow-ups.

Apply backend migrations and configure VERIQORN_STORAGE_ENCRYPTION_KEY before
saving a connection. See [storage setup](../object-storage.md). The encryption
key must be backed up separately from the database. Reverting the attachment
migration requires first removing references to saved connections.

The S3 protocol, encrypted persistence, switch behavior, administrator permissions,
and real PostgreSQL migration/import paths are covered by automated checks.
Operators must still check their actual AWS bucket, IAM/KMS policy, and large
attachments before production activation.
