# Veriqorn Enterprise v0.2.40

- Add optional Reasoning effort in LLM settings for LM Studio, Ollama and custom compatible endpoints, including Provider default and None. Pass the selected value through normal and streamed completions and connection tests.
- Treat empty/reasoning-only completions as errors. Failure analysis now exposes its deterministic fallback warning instead of silently labeling it as a model answer; connection tests report failure and chat surfaces an error instead of saving an empty assistant reply.
- Show the actual connection-test success or failure in the settings UI.
- Preserve FFF repository retrieval and the explicit private-origin policy from v0.2.39.

For local models that spend a small response budget entirely on reasoning, select Reasoning effort: None when the model supports it. Provider default preserves existing model behavior. Update both Enterprise images together.
