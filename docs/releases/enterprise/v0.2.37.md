# Enterprise v0.2.37

- Resolve the default project to the same canonical ID when building, loading and searching repository indexes.
- Keep catalog summaries, KB and coverage consumers aligned with completed index jobs.
- Reuse valid legacy unscoped/default-alias catalogs and repository settings only for the canonical default project; other projects do not inherit them.
- Preserve existing project-scoped settings when both current and legacy entries exist.

This corrects the application index lifecycle from v0.2.36. FFF remains the default, with lexical fallback and the optional VERIQORN_AI_SEARCH_ENGINE=legacy override. No license changes or attachment moves are required.
