# Enterprise v0.2.36

- Use native FFF repository search by default for failure-analysis evidence, with lexical retrieval as an automatic fallback.
- Keep matching source text visible within bounded snippets and attach precise line references.
- Retrieve fresh source excerpts for follow-up questions in failure-analysis chat.
- Preserve project/repository filters, index catalog compatibility, and KB/coverage consumers.
- Package the pinned native search runtime for the same platform/libc as the immutable Community base images.

## Upgrade

Upgrade both Enterprise images together. Existing repository settings and catalogs are reused; the native index is warmed on first search. Set VERIQORN_AI_SEARCH_ENGINE=legacy in the backend environment to select the previous retriever.

For installations upgrading from v0.2.34 or earlier, also follow the [storage upgrade requirements](../v0.2.35.md). No existing objects are moved by storage activation.
